# Changelog

This file records notable repository changes. The project does not currently
publish versioned releases, so entries are kept under `Unreleased` until a
release process is established.

## Unreleased

### Added

- Repository documentation for setup, API usage, architecture, deployment,
  contributing, and security.
- GitHub issue, pull request, and CI templates.

### Documentation notes

- The current application supports PDF ingestion, hybrid dense/sparse
  retrieval, optional reranking, Gemini answer generation, streaming responses,
  and page-level source citations.
- Evaluation metrics are available when request samples or labeled evaluation
  data are present; this repository does not publish benchmark results.
